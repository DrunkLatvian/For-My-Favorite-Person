# Инструкция по управлению сайтом "Night Archives"

Привет! Этот файл — твоя шпаргалка по управлению сайтом. 
Мы обновили сайт: теперь он состоит из нескольких страниц, чтобы всё было более структурировано и красиво. Открытки теперь прячутся в конвертах!

---

## 1. Структура папок
Чтобы сайт отображал твои файлы, тебе нужно **самостоятельно создать две папки** (если они ещё не созданы) прямо рядом с HTML-файлами.

Создай папки с точными названиями:
1. `Photos` — сюда кладем картинки.
2. `Audios` — сюда кладем голосовые сообщения и музыку.

Твоя папка проекта должна выглядеть так:
```text
/ForGelya/
  ├── Audios/          <-- папка для аудио
  ├── Photos/          <-- папка для фото
  ├── index.html       (Главная страница: вход и чат)
  ├── postcards.html   (Открытки в конвертах)
  ├── gallery.html     (Галерея полароидов)
  ├── letter.html      (Письмо)
  ├── style.css        (Стили сайта)
  ├── common.js        (Логика звёзд и салюта)
  ├── chat_config.js   (Тексты чата)
  └── GUIDE.md         (эта инструкция)
```

---

## 2. Как добавить Фотографии (Галерея)
Открой страницу **`gallery.html`**. Там заложены 6 фотокарточек-полароидов.
Чтобы там появились твои фото, скопируй нужные фотографии в папку `Photos` и переименуй их строго так:
- `photo1.jpg`
- `photo2.jpg`
- `photo3.jpg`
- `photo4.jpg`
- `photo5.jpg`
- `photo6.jpg`

*(Если у тебя фото в другом формате, переконвертируй их в `.jpg` или измени расширение в файле `gallery.html`).*

---

## 3. Как добавить Аудио (Открытки, Письмо и Фоновая музыка)
Положи свои `.mp3` файлы в папку `Audios` и переименуй их так:

- `track1.mp3` — для Открытки 1 (файл `postcards.html`)
- `track2.mp3` — для Открытки 2 (файл `postcards.html`)
- `track3.mp3` — для Открытки 3 (файл `postcards.html`)
- `track4.mp3` — для Открытки 4 (файл `postcards.html`)
- `letter.mp3` — для Письма (файл `letter.html`)
- `bg_music.mp3` — для фоновой музыки. Это могут быть звуки леса или легкая музыка. (Она будет играть фоном и автоматически приглушаться, когда включаются голосовые сообщения).

---

## 4. Как редактировать ответы и кнопки в Чате (Дядя РомаСкрипт)
Весь текст чата находится в файле **`chat_config.js`**. 
Открой его в текстовом редакторе.

Если ты хочешь, чтобы кнопка открывала нужную страницу, используй зарезервированные ID (они уже настроены):
- `{ id: 'nav_postcards', text: "Открыть Открытки" }` — перейдёт на `postcards.html`
- `{ id: 'nav_gallery', text: "Смотреть Галерею" }` — перейдёт на `gallery.html`
- `{ id: 'nav_letter', text: "Прочитать Письмо" }` — перейдёт на `letter.html`

Чтобы добавить обычные ответы, используй любой другой ID (например `btn_secret`) и добавь его в блок `responses`.

---

## 5. Секретная звезда
Одна из звёздочек на небе (в правом верхнем углу) пульсирует чуть ярче остальных. При нажатии на неё теперь срабатывает салют, и браузер больше не зависает!

## 6. Как запустить сайт
Просто открой файл `index.html` в браузере. Введи пароль **2104**.
Из чата ты сможешь переходить на все остальные страницы по кнопкам, а с тех страниц — возвращаться обратно в меню.
